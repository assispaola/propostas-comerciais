02 / DIAGNÓSTICO & ESTRATÉGIA

Por que esse projeto importa agora

Contexto atual:

A GoodTruck já opera com processos manuais de gestão — voluntários, parceiros e comunidade coordenados por canais fragmentados, que limitam a capacidade de escala da operação conforme a ONG cresce.

Mais do que um sistema de cadastro, essa plataforma é o ponto único onde a GoodTruck gerencia pessoas, relacionamentos e prova de impacto: um portal centraliza o acesso de cada perfil de usuário, os dashboards tornam o impacto da operação visível — tanto para o público quanto para as empresas parceiras, reforçando transparência e justificando parcerias continuadas — e as automações reduzem a carga operacional da equipe no atendimento do dia a dia.

Protótipo de alta fidelidade antes do código

Toda a experiência é desenhada em alta fidelidade no Figma e validada pela GoodTruck antes de qualquer linha de código ser escrita, evitando retrabalho.

Entregas por fase, com transparência total

Reuniões semanais de acompanhamento, com reporte de progresso e validação formal ao fim de cada fase antes de seguir para a próxima.

03 / EQUIPE & STACK TÉCNICA

Stack técnica

Diferencial da equipe

Nossa equipe cobre front-end, back-end e UX/UI design na mesma dupla. Isso significa que antes de qualquer linha de código, a GoodTruck recebe um protótipo de alta fidelidade completo no Figma, documentado e pronto para handoff — com especificações claras de componentes e comportamento — garantindo fidelidade total entre o que é aprovado e o que é desenvolvido.

Frontend — Angular + TypeScript

Portal responsivo, formulários, dashboards e áreas específicas para cada perfil de usuário.

Backend — Java com Spring Boot

APIs, regras de negócio, autenticação, autorização e integração entre os módulos.

Dados — PostgreSQL e armazenamento em nuvem

Banco transacional para cadastros e estrutura de armazenamento e processamento de dados dimensionada conforme as fontes e os volumes.

Dashboards — biblioteca de gráficos integrada

Painéis de indicadores implementados diretamente no portal, com atualização conforme os dados da plataforma.

Chatbot — API de serviço especializado

Integração com uma solução existente, com definição dos fluxos de atendimento e dos limites de uso.

Para este projeto, também estão previstos controle de acesso por perfil, boas práticas de segurança, logs de auditoria, backups, documentação técnica e cuidados com a LGPD.
